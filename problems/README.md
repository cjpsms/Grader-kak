# โจทย์

โจทย์ที่ใช้ในระบบ Grader นี้ เป็น **โจทย์จาก POSN KP 1 และโจทย์อื่นๆ ที่ทำกันเอง** (ผู้ดูแล/เพื่อนๆ ออกเอง)

- ไฟล์ในโฟลเดอร์นี้เป็นโจทย์ (PDF) เท่านั้น **ไม่มีเทสต์เคสและเฉลย** เทสต์เคสอยู่ในข้อมูลของระบบ (`data/problems.json`) ซึ่งไม่ได้เผยแพร่
- โจทย์ที่มาจาก POSN KP 1 เป็นสิทธิ์ของผู้จัด/ผู้ออกโจทย์เดิม นำมารวมไว้เพื่อการเรียนและฝึกซ้อมเท่านั้น หากเจ้าของโจทย์ต้องการให้นำออก แจ้งได้ที่ Issues ของ repo นี้
- โฟลเดอร์แบ่งตามโปรเจกต์ในระบบ ชื่อไฟล์ตัดเลขเวลาที่อัปโหลดออกแล้ว
