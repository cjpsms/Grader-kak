วิธีเขียนเทสเคส (ละเอียด)

1 บรรทัด = 1 เคส เขียนเป็น input => expected ซ้ายมือคือข้อมูลที่ป้อนเข้าโปรแกรม (stdin) ขวามือคือ output ที่ถูกต้อง บรรทัดว่างจะถูกข้าม

input หรือ expected หลายบรรทัด ให้ใช้ \n แทนการขึ้นบรรทัดใหม่ เพราะ 1 เคสต้องอยู่ในบรรทัดเดียว

เครื่องหมาย \ จริงๆ ให้พิมพ์ \\ เช่น a\\nb จะได้ตัวอักษร a \ n b (ไม่ขึ้นบรรทัดใหม่)

ว่างเปล่าได้ทั้งสองฝั่ง เช่น => x (ไม่มี input) หรือ 5 => (ไม่มี output)

ตัวอย่าง

1 2 => 3
3\n10\n20\n30 => 60
3\n3 1 2 => 1\n2\n3
hello world => HELLO WORLD

เคสที่ 2 ป้อน 4 บรรทัด (3, 10, 20, 30) คาดหวัง output 60 · เคสที่ 3 ป้อน 2 บรรทัด (3 และ 3 1 2) คาดหวัง output 3 บรรทัด (1, 2, 3)

การเทียบคำตอบ: ระบบถือว่า CRLF เท่ากับ LF และตัดช่องว่าง/บรรทัดว่างที่หัวและท้ายของ output ทั้งก้อนก่อนเทียบ แต่ช่องว่างระหว่างคำและท้ายแต่ละบรรทัดต้องตรงเป๊ะ (1 2 ไม่เท่ากับ 1 2)

ข้อจำกัด: ใช้ => ได้ 1 ครั้งต่อบรรทัด (ตัวหลังจะถูกตัดทิ้ง) ถ้า input หรือ expected ต้องมี => ให้สร้างด้วยเคสอื่นก่อน แล้วไปแก้ที่ปุ่ม "แก้ไข" ในรายการโจทย์ ซึ่งไม่มีการแปลงตัวอักษรพิเศษ

สร้างแล้วแก้ทีหลังได้ที่ปุ่ม "แก้ไข" ข้างโจทย์ (รูปแบบ @@ input / @@ expected ซึ่งขึ้นบรรทัดใหม่ได้จริง)
